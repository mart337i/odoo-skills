# Grill Me

Interview the user relentlessly about every aspect of this plan until there is shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one by one.

Ask exactly one question at a time. For each question, include your recommended answer.

If a question can be answered by exploring the codebase, inspect the codebase instead of asking.
